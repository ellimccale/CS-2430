# Project 1 - Sorting Algorithm Comparison

CS-2430: Discrete Structures

Implements and compares merge sort, quick sort, heap sort, and shaker sort by counting element comparisons across input sizes n = 4, 6, and 8.

## Requirements

- Java 22 (check with `java -version`)
- No external dependencies

## Build and Run

From `/project1`:

	javac -d out src/*.java
	java -cp out Main

Or in Eclipse: right-click `Main.java` -> Run As -> Java Application.

No command-line arguments required; input sizes and data generation are hard-coded.

Output is printed to stdout. To capture:

	java -cp out Main > output/results.txt
